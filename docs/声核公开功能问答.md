# 声核公开功能问答

供声核用户支持查阅。版本、兼容性及界面以已发布的对应版本和官网为准。遇到版本不明或没有公开依据的情况，先确认现象与版本，再给可以验证的步骤。

查询最新版时使用官网发布信息。排查故障时可以请对方描述版本、设备类别、预期、实际现象和最短复现步骤。公开回复只使用与问题直接相关的已公开功能说明。

## 安装、更新和初次使用

### 查询正式版版本或查看公开更新说明

官网的下载页可以查看当前正式版和公开更新说明。

[公开说明](https://audcore.utae.cn/download/)

### 第一次连接麦克风和耳机

从一条通道开始。在设置添加输入与输出，再在通道里选择麦克风和耳机。先调低监听音量，确认说话时通道有电平且耳机能听见。

[公开说明](https://audcore.utae.cn/guide/)

### 关闭窗口与退出声核

关闭窗口后，声核仍在托盘运行并继续处理声音。需要结束处理时，从托盘菜单选择「退出声核」。

[公开说明](https://audcore.utae.cn/guide/)

### 便携单文件版数据位置

保存下载的单文件完整文件名。以 -portable.exe 结尾时会使用程序旁的 Audcore-data。搬到另一台电脑前，先正常退出并备份预设和这个数据目录。

[公开说明](https://audcore.utae.cn/preset-guide/)

## 输入输出与声音来源

### 没有 ASIO / 添加 WASAPI 设备

在设置的输入输出设备表分别添加所需的 WASAPI 输入和输出，再回到调音台为通道选择设备。没有 ASIO 驱动也可以使用。

[公开说明](https://audcore.utae.cn/wasapi/)

### 捕获系统播放声音

在设置中打开「输出设备作为输入」，再添加要采集的播放设备，并在通道里选作输入。WASAPI 播放回环使用共享模式。

[公开说明](https://audcore.utae.cn/wasapi/)

### 设置虚拟跳线

先确认声核与接收软件之间需要哪一路信号。将那一路送到声核配置的虚拟输出，再在接收软件里选同一组对应的录音端点。

[公开说明](https://audcore.utae.cn/virtual-routing/)

### 播放本地音频文件

在通道里添加「媒体播放」效果器，再选择或拖入音频文件。它支持播放、暂停、定位和循环，声音可以继续送往该通道的效果器和输出。

[公开说明](https://audcore.utae.cn/media-player/)

### 截获支持的音乐播放器

启动播放器后，在通道输入中选择「截获播放器」，播放音乐并检查通道电平。接入时播放器原声会静音，停止接入后恢复。兼容性取决于播放器的版本和音频输出方式。

[公开说明](https://audcore.utae.cn/player-capture/)

### 捕获指定程序及处理重复监听

「捕获程序声音」把程序播放的声音复制一份给声核，原声仍从原设备播放。听到两份时，让耳机只保留原声或处理后声音的一条监听路线。

[公开说明](https://audcore.utae.cn/guide/)

### 麦克风接管的用途与共享模式

麦克风接管是测试功能，适用于 Windows 共享录音。其他软件可以继续选择原麦克风来收声核处理后的信号。通道里使用「接管前原声」作输入，避免把已经处理的声音再次送回同一设备。

[公开说明](https://audcore.utae.cn/mic-takeover/)

## 路由、监听与直播

### 输入、发送及最终输出的无声排查

先看输入通道有没有电平，再看发送目标和最终输出通道是否依次有电平。如果声核最终输出有电平，再检查接收软件选的音频设备是否对应。

[公开说明](https://audcore.utae.cn/routing-guide/)

### 发送取点与发送音量

在发送行右键可以调音量和选取点。效果前取未处理的声音，效果后推子前取经过效果器的声音，推子后还会跟随通道推子的音量。

[公开说明](https://audcore.utae.cn/sends-sidechain/)

### 侧链发送

先在目标通道加载支持侧链输入的效果器。再到来源通道下方点「＋」，从侧链目标里选择该效果器。

[公开说明](https://audcore.utae.cn/sends-sidechain/)

### 用快捷键切换说话与唱歌通道

可以把说话和唱歌做成独立通道，再用输入互斥和快捷键切换。耳返与直播混音可分别安排发送。

[公开说明](https://audcore.utae.cn/channel-switching/)

### 通过网页源把声音送到 OBS

在要输出的通道上添加网页源发送并复制地址。使用同一台电脑，在 OBS 里添加浏览器源，粘贴地址并启用「通过 OBS 控制音频」。

[公开说明](https://audcore.utae.cn/source/help/)

### 爆音、杂音及延迟排查

先比较声核耳返和接收软件里的声音，再看输入电平是否过载。如果耳返也有断音，可以适当增加设备缓冲。如果添加某个效果器后延迟增大，可以旁通它做对照。

[公开说明](https://audcore.utae.cn/audio-troubleshooting/)

## 录音、效果器与工程

### 开始录音与查看文件

点通道的 REC 开始录制，再点一次停止。设置里的「通道录制」可选择保存目录和格式，也能打开目录。修改会在下次录制时生效。

[公开说明](https://audcore.utae.cn/recording/)

### 录音通道没有声音 / 录制人声与伴奏

录音前先确认要录制的通道有电平。要把人声和伴奏录到同一份文件，先将它们汇到同一个通道，再录制这个通道。

[公开说明](https://audcore.utae.cn/recording/)

### 同时录制干音、湿音和最终混音

让麦克风先接到没有效果器的干音通道，再发送到加了效果器的湿音通道。两条通道分别开启 REC 就能分别保存。最终混音也可以在汇总通道单独录。

[公开说明](https://audcore.utae.cn/recording/)

### 扫描或加载 VST3

先确认安装的是 64 位 VST3，再在声核里扫描后添加。某个插件加载异常时，可以先确认其他 VST3 能否加载，以缩小排查范围。

[公开说明](https://audcore.utae.cn/plugin-guide/)

### 预设备份及迁移

换电脑前先保存并备份预设。目标电脑还需要安装工程用到的效果器。打开预设后，检查输入输出设备与通道路由。

[公开说明](https://audcore.utae.cn/preset-guide/)

### 导入 Studio One 或 REAPER 工程

可以导入 Studio One 的 .song 和 REAPER 的 .rpp 工程中声核能识别的部分。导入后要逐项核对效果器、音频设备和路由。

[公开说明](https://audcore.utae.cn/project-import/)

### 工程导入的兼容边界

工程导入用来迁移通道、可识别的 VST3 状态和部分路由。时间轴、音频片段、MIDI 和自动化继续在原工作站处理。

[公开说明](https://audcore.utae.cn/project-import/)

## 扩展开发

### 网页与原生皮肤开发资料

可用 WebView2 网页开发皮肤，也可用公开的 C ABI 做原生皮肤。开发页提供接口与最小样例，皮肤包统一使用 .skin.audcore 扩展名。

[公开说明](https://audcore.utae.cn/skin-dev/)

### 本地公开 API 和 SDK

本地 API 与 SDK 用于独立应用读取和控制声核，可按官方文档使用实时订阅。先确认用户已在声核里启用接口。

[公开说明](https://audcore.utae.cn/api/)

## 更多常见问题

### 声核适合怎样的工作？

声核面向 Windows 实时音频处理、直播、监听和通道录制。标准版的主界面是实时调音台。需要时间轴、素材编辑或自动化编排时，在对应工作站完成。

[公开说明](https://audcore.utae.cn/guide/)

### ASIO 和 WASAPI 怎么选？

带厂商 ASIO 驱动的声卡可以通过 ASIO 接入。集成声卡、USB 麦克风与普通耳机可以直接用 WASAPI。选了 ASIO 也能独立添加额外的 WASAPI 输入与输出，切换 ASIO 会保留这些设备配置。

[公开说明](https://audcore.utae.cn/wasapi/)

### WASAPI 共享和独占模式有什么差别？

共享模式方便多个程序同时使用设备，采样率跟随 Windows 中的设备混音格式。独占模式可选择设备支持的采样率及缓冲，设备被其他应用占用时可能无法打开。

[公开说明](https://audcore.utae.cn/wasapi/)

### 设备旁显示的是完整耳返延迟吗？

那里显示的是设备缓冲折算的时间。实际从麦克风到耳机还可能经过效果器、路径对齐、其他设备缓冲或蓝牙链路。

[公开说明](https://audcore.utae.cn/wasapi/)

### 硬件回环、虚拟跳线和网页源怎么选？

支持回环的声卡可把混音送到自己的回环。需要跨软件传递音频且没有合适回环时，可选虚拟跳线。在同一台电脑的 OBS 中，也可以用声核网页源。选一条可用的路线，避免 OBS 同时采集同一份声音。

[公开说明](https://audcore.utae.cn/routing-guide/)

### 多核心并行和延迟对齐有什么作用？

多核心并行主要分担彼此独立的处理路线，效果链内部仍按顺序执行。延迟对齐让并行路线在合并时更接近同一时刻，可能增加部分路线的等待时间。

[公开说明](https://audcore.utae.cn/guide/)

### 效果器休眠会发生什么？

兼容效果器在输入、输出接近静音且尾音结束后可以暂停处理，声音回来时恢复。自动旁通休眠和静音休眠是不同选项。效果器状态仍保留。

[公开说明](https://audcore.utae.cn/guide/)

### 第三方效果器开窗出错怎么缩小范围？

先用空预设单独测试该效果器，分清问题发生在扫描、添加、开窗、关窗还是退出；记下公开可分享的软件版本、插件型号和最小步骤。确认插件安全且问题已处理后，再考虑解除隔离并重扫。

[公开说明](https://audcore.utae.cn/plugin-guide/)

### 怎么选录音格式？

优先按后续软件的兼容性和用途选择。WAV 适合常见编辑流程，CAF 浮点适合声核的高动态工作流程，FLAC 适合无损节省空间，Opus 适合体积优先的试听或留档。具体可选格式以当前版本设置为准。

[公开说明](https://audcore.utae.cn/recording/)

### 效果链导入后，为什么还需要设置设备？

效果链帮助复用处理和参数。第三方 VST3 要先在本机安装和授权，导入后再为当前电脑选输入、输出和发送目标。

[公开说明](https://audcore.utae.cn/guide/)

### 还有哪些效果器可用？

效果器大全按用途列出降噪、均衡、压缩、混响、去齿、限幅、延迟等。可先用声核内置版试听。某些效果器另有独立 VST3，是否有对应版本以其公开产品页为准。

[公开说明](https://audcore.utae.cn/effects/)

### 如何开发 IO 扩展或独立效果器？

IO 扩展从公开清单、端点与 PCM 示例开始。独立效果器从公开 ABI 和增益样例开始，按页面说明核对所用版本的参数、状态及打包接口。

[公开说明](https://audcore.utae.cn/io-dev/)

### 哪里能找到独立效果器的开发接口？

公开开发页提供 ABI、参数与状态、实时处理、原生界面与打包的说明。以当前公开 SDK 和实际运行版本为准。

[公开说明](https://audcore.utae.cn/fx-dev/)
